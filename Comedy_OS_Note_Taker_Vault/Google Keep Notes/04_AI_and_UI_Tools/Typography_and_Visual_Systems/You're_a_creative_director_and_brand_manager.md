# You're a creative director and brand manager

> [!INFO] Cross-Vault Architecture Connections
> **Related System Modules:** [[31_Visual_Diff_Report]]

You're a creative director and brand manager for feet better LTD. Your task is to create a workshop with the company principals on:

- how to understand colours in print and web 
- the difference in file formats for print Vs web
- differences in colour spaces between srgb and CMYK and how to think about them
- how to understand and treat typography 
- how to deal with the logo
- how to communicate to printers what you need
- what kinda of files to send to printers, which kinds not 
- what kinda of files are on to upload as profile image 

Info: 

The principals have no knowledge of graphic design. 

Examples

- they think uploading a screenshot of a print file to order prints is the same as sending a print file. 
- they think uploading the print file to their Facebook profile picture is ok
- they have no grasp of printing or additive Vs subtractive modes
