# Google Messages Frustrations & Needs

Features the Author Needs and Would Find Delightful

Auto-Delete for Old Messages: An optional feature with a customizable age threshold that automatically deletes older, irrelevant threads or moves them to the trash. 

A "Select All" Button: A one-tap button to select every message on a screen at once, specifically requested for the "Spam and blocked" and "Archived" pages. 

Hold and Drag to select multiple, hover button select all. 

Select only specific user's messages: select your messages, select specific user's messages


Two "Start Chat" Buttons: A dual-button system where one button starts a chat with an individual, and a second button pulls up a list of previously created groups so the user can easily message all members. 

Partial Text Copying: The ability to highlight and copy just a specific portion of a message, rather than being forced to copy the entire text bubble.

List of Frustrations
Manual Inbox Maintenance: Old, irrelevant threads endlessly pile up, forcing the user to manually spot and delete them to keep the inbox clean. 

Tedious Spam Deletion: Because there is no "Select All" option, clearing out the spam folder takes far longer than it should since the user must individually long-press and select every single spam message. 

Clunky Group Messaging: Tapping the current "Start chat" button only gives the option to create a new group; it doesn't allow the user to quickly select an existing group to drop a message into. 

Missing Basic Functionality: It is highly annoying that a basic feature like copying a specific part of a message is still missing in 2026. 

Slow Development Pace: The author is frustrated by how long it takes Google to work on highly requested basic features, noting that if rumored features get delayed or scrapped, it will be even more aggravating.

The "Can't Quit" Paradox: The ultimate frustration is that despite all of these missing basic functions and annoyances, the app has just enough good features that the author feels locked in and cannot bring himself to switch to a competitor.
