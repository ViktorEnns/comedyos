# Automatic “Writing”, “Ghost”, “Ultra Ghost” Modes - Suppress all notifications (offline mode light). Comedy OS Feature - MVP

#comedyos #feature #mvp

Automatic “Writing”, “Ghost”, “Ultra Ghost” Modes - Suppress all notifications (offline mode light). 

Writing Mode

Stop distractions in their root. Suppress all notifications and alerts except from Comedy OS (or a selected filter of apps / functions). Minimize / Close the app to return default functionality.

Ultra Ghost Mode / Performance Mode (available in writing mode)

It’s you and the audience. Nothing else matters at that moment. In Performance Mode turn off / suppress everything that could distract except Comedy OS.

Ghost Button

The button is to turn Ghost Mode off. It is on by default. It is symbolized in the UI so the user knows which state the app is currently in. Tapping the symbol will deactivate Ghost Mode.
